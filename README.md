---

### the setup

hetzner cloud, provisioned with opentofu, configured with nixos (flake-parts). everything declarative, everything reproducible. if a server explodes i can just... make another one.

secrets live in sops (`secrets/`), backed by 1password. ssh keys get generated by opentofu and tucked safely into the vault. the opentofu state is encrypted with a key from sops.

---

### what lives here

**matrix** - chat server, encrypted and private

**memos** - simple note-taking for thoughts that need saving

**firefly** - personal finance tracker, theoretically useful

**affine** - workspace for docs and planning, notion alternative

**pocket id** - clean oidc provider for single sign-on

**netbird** - wireguard-based mesh vpn with proper access control

**attic** - a nix binary cache connected to a s3 bucket

### layout

- `hosts/default.nix` - inventory, the one place a machine is declared
- `hosts/<name>/` - per-host nixos config
- `modules/nixos/` - `core/` (site, ssh, caddy, nix) and `services/`
- `modules/nixos/profiles/` - `server` (hetzner vm, the only profile so far)
- `flake/` - flake-parts modules, `lib/` - nix helpers
- `infra/` - opentofu, `scripts/` - deploy helpers

---

### adding a new server

1. add it to `hosts/default.nix` with `hcloud.serverType`
2. make a home for it in `hosts/<name>/`
3. `tf apply` to birth the box (dns comes from its caddy sites)
4. `deploy <name>` to give it life
